# Roadmap

Trade Pipeline is evolving as an auditable document workflow for small manufacturing-export teams. Items below are directions, not release commitments.

## Current focus

- Make initial setup, sample data, and first successful run easier to verify.
- Improve the de-identified demo path from RFQ to quotation, PI, commercial invoice, and packing list.
- Collect installation and workflow feedback from small industrial-export teams.

## Candidate extensions

- Draft-only customer email and follow-up assistance.
- Structured export data packs for customs-broker preparation.
- Historical quotation reference and customer-profile insights.
- Reviewable quotation suggestions that never replace human approval.

Trade Pipeline will remain distinct from ERP: it does not aim to own inventory, finance, taxation, or enterprise-wide operations.
