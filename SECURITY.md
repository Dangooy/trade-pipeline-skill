# Security Policy

## Supported versions

Security fixes are considered for the current default branch.

## Reporting a vulnerability

Do not open a public issue for suspected security vulnerabilities or exposed sensitive data.

Use GitHub's private vulnerability-reporting channel when it is available for this repository. If it is not available, contact the maintainer through the GitHub profile and include only the minimum information needed to establish a secure reporting path.

## Scope

Please report issues such as credential exposure, unsafe file handling, prompt-injection paths, unintended network access, or actions that could disclose business data.
